# TP3: Linear and Logistic Regression (Classic vs. Trained)

This folder contains the practical implementation and solutions for **Series No. 2: Classic Regression vs. Trained Regression**, dedicated to the **Master GRH and Management** program at the **University of Eloued**.

##  Project Overview
The objective of this TP is to contrast the traditional statistical approach to regression (In-Sample inference using `statsmodels`) with the modern machine learning paradigm (Out-of-Sample predictive generalization using `scikit-learn`).

### 📂 Contents
The repository includes implementations for both simple and multiple datasets covering:
1. **Linear Regression:** Traditional Ordinary Least Squares (OLS) estimation vs. Trained predictive models.
2. **Logistic Regression:** Traditional logistic modeling vs. Machine learning classification models.

##  Main Tasks Covered
- **Classical Estimation:** Building OLS models on full datasets and evaluating in-sample metrics (MSE, \(R^2\), and Adjusted \(R^2\)).
- **Data Partitioning:** Implementing manual array slicing and automated splitting using `train_test_split`.
- **Model Evaluation:** Analyzing model performance using out-of-sample test metrics like Mean Squared Error (MSE) and Root Mean Squared Error (RMSE).
- **Methodological Comparisons:** Investigating critical machine learning and statistical concepts such as Overfitting, Multicollinearity, and the Bias-Variance Tradeoff.

##  Tech Stack
- **Language:** Python
- **Libraries:** `Jupyter Notebook`, `pandas`, `numpy`, `matplotlib`, `statsmodels`, `scikit-learn`
